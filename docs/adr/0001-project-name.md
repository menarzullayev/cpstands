# ADR 0001: Project name

- Status: accepted (2026-11-08)
- Decision: **cpstands**.
- Why: describes the product (competitive programming + standings), English, globally readable.
- Measured on 2026-11-08: free on `.uz`, `.com`, `.io`, GitHub user/org, `@cpstands_bot`, `@cpstandsbot`,
  and the `t.me/cpstands` namespace. Instagram was not checked (cannot be verified over plain HTTP).
- Alternatives considered: natijacp (also fully free, local flavour), verdictlive (`.com` taken), cpwatch, contestly, solvelog.
- Follow-up: register the bot, domain, and channel handles promptly; they are a snapshot, not a reservation.
