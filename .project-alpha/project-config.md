## Product
- One-line idea: Live competitive-programming contest tracker for Telegram: standings, reminders, solve alerts for Codeforces and kep.uz, in uz/ru/en
- Target market: Competitive-programming communities worldwide (Telegram groups and private users); Uzbekistan first
- Primary user: A contest participant who follows rounds together with friends; secondary: community or group admins
- Product status: pre-alpha, design phase

## Constraints
- Budget: minimal; free-tier or low-cost hosting at early scale
- Team: one maintainer plus AI agent assistance
- Timeline: first public release targeted for the next contest cycle after stage 10 passes; see development plan
- Technical constraints: Codeforces public API (about 1 request per 2 s, no extra standings parameters); Telegram Bot API limits; kep.uz without written terms
- Regulatory constraints: privacy policy published; no personal data in public documents; data deletion on request
